Causal Discovery (17 algorithms)

Constraint-Based

PC Algorithm — Classic constraint-based CPDAG search.
Fisher Z stable PC 
import { pcAlgorithm } from '@agentix-e/causality-analyzer-pipeline';
import { Matrix } from 'ml-matrix';

const data = new Matrix([[1,2,3],[4,5,6],[7,8,9]]);
const { graph, sepSet } = pcAlgorithm(data, ['X', 'Y', 'Z']);
FCI Algorithm — Handles latent confounders via PAG output (R1-R10).
GFCI — FGES + FCI hybrid. RFCI — Fast PDS-free variant. 
import { fciAlgorithm, gfciAlgorithm, rfciAlgorithm } from '@agentix-e/causality-analyzer-pipeline';
const { graph, pagEdges } = gfciAlgorithm(data, ['X', 'Y', 'Z', 'U']);

Score-Based & Permutation

GES — Greedy Equivalence Search (CPDAG space).
BOSS — Best Order Score Search (NeurIPS 2023, permutation space).
GRaSP — L1-regularized + covered tuck permutation search. 
import { gesAlgorithm, bossAlgorithm, graspAlgorithm } from '@agentix-e/causality-analyzer-pipeline';
const dag = bossAlgorithm(data, ['A','B','C','D'], { numStarts: 3 });

Continuous Optimization

NOTEARS — Trace-exponential DAG constraint + L-BFGS.
DAGMA — Log-determinant constraint (more stable than NOTEARS). 
import { notearsAlgorithm, dagmaAlgorithm } from '@agentix-e/causality-analyzer-pipeline';
const { graph } = dagmaAlgorithm(data, ['X','Y','Z']);

Specialized

LiNGAM — Non-Gaussian ICA-based.
FASK — Skewness-based orientation.
KCI — Kernel conditional independence test.
CD-NOD — Domain-shift causal discovery.
MVPC — Missing-value PC.
RCD — Reinforced BIC orientation.
TS-ICD — Time-series discovery.
Targeted Discovery — Find parents of specific nodes.

Root Cause Analysis

import { CausalGraph, HeuristicPathRCA, CIRCAPipeline } from '@agentix-e/causality-analyzer-pipeline';

const graph = new CausalGraph(['CPU', 'Memory', 'Latency']);
graph.addEdge('Memory', 'CPU');
graph.addEdge('CPU', 'Latency');

const rca = new HeuristicPathRCA();
rca.train(graph, new Set(['CPU', 'Latency']), data);
const result = rca.findRootCauses(['CPU', 'Latency']);
console.log(result.rootCauses[0].name);  // "Memory"

Algorithm Selection Guide

ScenarioRecommended Algorithm
Fast discovery, no latentsPC (constraint) or GES (score)
Best accuracy, moderate size (<30 nodes)BOSS (permutation)
Latent confounders suspectedGFCI (PAG) or RFCI (fast PAG)
Non-Gaussian dataLiNGAM or FASK
Time-series dataTS-ICD
Streaming/onlineOnlinePC
Missing valuesMVPC
Continuous optimizationDAGMA (preferred) or NOTEARS
Large graphs (>50 nodes)RFCI or BOSS (permutation)
